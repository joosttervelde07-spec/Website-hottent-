# Hottent bouwregels

## Doel
De website moet rustig, avontuurlijk en functioneel aanvoelen.
Geen webshop-look en geen overdreven design.

## Techniek
- Alleen HTML en CSS
- Geen JavaScript tenzij echt nodig
- Geschikt voor JouwWeb HTML-elementen
- Mobile first
- Semantische HTML gebruiken
- Geen inline styling
- Geen nieuwe kleuren buiten het centrale CSS-bestand
- Geen nieuwe class-namen maken als bestaande classes bruikbaar zijn

## Structuur artikel
1. Label
2. H1 titel
3. Korte intro
4. Hoofdafbeelding
5. Artikeltekst
6. Eventueel tip- of infoblok
7. Afsluiting
8. Link terug naar thema

## CSS
Alle vormgeving komt uit hottent.css.
HTML bevat alleen structuur en inhoud.

## Stijl
- rustige natuurlijke kleuren
- ruime witruimte
- duidelijke typografie
- weinig decoratie
- foto's groot laten werken
- geen collagevormen
